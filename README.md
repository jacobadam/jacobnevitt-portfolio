# Jacob Nevitt Portfolio

Personal portfolio website built to showcase projects, skills, and experience as a frontend / full-stack developer.

## Live Site

https://www.jacobnevitt.com/

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- ESLint

## Features

- Modern dual-page portfolio layout
- Fully responsive design
- Optimised for performance and accessibility
- Clean, minimal UI with reusable components
- Fast builds using Next.js App Router

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- pnpm

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Runs the app locally at:
http://localhost:3000

### Build

```bash
pnpm build
```

### Production

```bash
pnpm start
```

## Project Structure

```
/app        # App Router pages, layouts, and sections
/components # Reusable UI components
/globals.css # Global styles and Tailwind entry
```

## Scripts

- pnpm dev - Start development server
- pnpm build - Create production build
- pnpm start - Run production server
- pnpm lint - Run ESLint

## Notes

- Built with a focus on performance, accessibility, and simplicity
- Uses Tailwind CSS v4 for styling
- Uses the Next.js App Router for modern routing and layouts
